## HONEST CAVEAT — read first

These are REAL photos of the CORRECT SUBJECT, but they are representative /
file photos, NOT photographs of the exact 23 Nov 2026 moment. No photo
here is verified as taken on 23 Nov 2026: the 23 Nov events themselves
(a board decision, an unverified IRGC claim, a virtual FIFA congress,
a leaked dataset) mostly have no publishable "moment" photo, and
image-search results do not carry reliable dates. Each row below says
exactly what the photo is. Same approach as the 22 Nov entry (v3c),
which the user approved with these caveats on record. The vector version
(news-v1-23nov-a.png, same layout/data, all art drawn in code) remains
available if the user prefers zero photo risk.
